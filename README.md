# Divyang-Sahayak React Frontend

## Run in VS Code
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal and run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

The UI includes Sign up, My donations, Item status, Device inventory, NGO requests, Notifications, Resale items, and Profile settings. Data is saved to browser localStorage for demo purposes only. There is no backend, real authentication, email service, verified NGO process, or live marketplace transaction.
